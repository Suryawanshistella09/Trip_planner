**Trip Planner Web Application**

A simple and interactive Trip Planner Web App that helps users organize their travel plans efficiently.
Users can manage destinations, plan itineraries, track expenses, and prepare packing lists for their trips.

📌 Features

🗺️ Destination Planning – Add and manage travel destinations.

📅 Trip Itinerary – Plan daily activities for your trip.

💰 Expense Tracker – Record and manage travel expenses.

🎒 Packing Checklist – Create and manage packing lists.

👥 Group Travel Planning – Organize trips with friends or family.

🎮 Gamification – Adds interactive elements to make planning fun.

🛠️ Technologies Used

HTML5

CSS3

JavaScript

Node.js (for project setup)
